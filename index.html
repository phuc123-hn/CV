NCKH cấp Khoa — Hệ thống hỗ trợ phân tích và phát hiện mã độc dựa trên đặc trưng tĩnh & Machine Learning

Kết quả nghiệm thu

Đề tài nhóm 2 sinh viên (GVHD: ThS. Trần Bá Minh Sơn) — trực tiếp xây dựng toàn bộ pipeline Machine Learning và ứng dụng web.

  • Xây dựng hệ thống phát hiện mã độc file PE dựa trên 2.381 đặc trưng tĩnh, sử dụng bộ dữ liệu chuẩn EMBER 2018 (600.000 mẫu có nhãn), trích xuất bằng thư viện LIEF
  • Huấn luyện, so sánh 3 mô hình Machine Learning (XGBoost, LightGBM, Random Forest); XGBoost đạt F1-score 96,82% và ROC-AUC 99,38% trên tập kiểm thử độc lập 200.000 mẫu
  • Áp dụng Youden's J Statistic để tối ưu ngưỡng phân loại, giảm 43% tỷ lệ cảnh báo nhầm (False Positive Rate) so với ngưỡng mặc định
  • Xây dựng Evidence Aggregation Framework kết hợp SHAP và Import Pattern Engine ánh xạ MITRE ATT&CK để giải thích quyết định phân loại theo từng mẫu; triển khai ứng dụng web bằng Flask với nhật ký phân tích thời gian thực
